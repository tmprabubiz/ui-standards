## App-building standards

For any app idea, feature, workflow, domain constraint, API/data design, build-machine
limit, remote build, cloud resource or deployment question, use the `ui-standards` skill
at `.claude/skills/ui-standards/SKILL.md`. Keep `docs/ui-standards/COVERAGE.md` and
`docs/ui-standards/NEXT-ITERATION.md` current.
When the owner asks "what am I missing" or "what next", use it in ADVISE mode.
Before writing UI code, complete and get owner approval for each screen block in
`docs/ui-standards/SLICE-WALKTHROUGH.md`; do not build an unconfirmed screen.
