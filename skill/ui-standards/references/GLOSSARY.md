# Plain-word glossary

Use the plain wording first. Put the technical term in parentheses only when it helps the
builder. Explain any term not listed here the first time it appears.

| Technical term | Say this to the owner |
|---|---|
| Indeterminate / mixed state | Some items are selected, but not all |
| Idempotency | Repeating the same request will not repeat the action or charge |
| API | The connection one part of the app uses to ask another part to do something |
| Endpoint | One named action available through that connection |
| Migration | A safe change to the way the app stores its data |
| Soft delete | Move to a recovery bin instead of erasing right away |
| Retry | Try the failed action again |
| Outcome unknown | The app cannot yet tell whether the service finished the action |
| Rate limit | A cap on how often an action can run |
| Signed link | A private link that expires and only grants the stated access |
| Screen reader | Software that reads the screen aloud or as Braille |
| Focus | The control that will respond to the next keyboard action |
| Validation | Checking that information is complete and usable |
| Dry run | Preview what would happen without doing the paid or lasting action |
| Ledger | A record of what was run, when, and what it cost |
| Partial result | Some items worked and others did not |
| Local-first | The app saves on this device unless the owner chooses to sync |
